# Archivo Black provenance

This repository vendors the latin-subset webfont used by the Home event title.

- Family: Archivo Black
- Local file: `archivo-black-latin.woff2`
- Source family directory: https://github.com/google/fonts/tree/main/ofl/archivoblack
- Google Fonts CSS source: https://fonts.googleapis.com/css2?family=Archivo+Black&display=swap
- Retrieved webfont URL: `https://fonts.gstatic.com/s/archivoblack/v23/HTxqL289NzCGg4MzN6KJ7eW6CYyF_g.woff2`
- Copyright: 2017 The Archivo Black Project Authors, https://github.com/Omnibus-Type/ArchivoBlack
- License: SIL Open Font License 1.1; see `OFL.txt` in this directory.

The font is loaded from the repository with `font-display: swap`; the site does not request a network font at runtime.
