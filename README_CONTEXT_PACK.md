# Qiskit Context Pack V1

Files:
- `AGENTS.md` — authoritative agent operating rules.
- `agent_docs/project_overview.md` — product and current project shape.
- `agent_docs/design_system.md` — visual/interaction system.
- `agent_docs/decisions.md` — LOCKED / PROVISIONAL / OPEN / SUPERSEDED decisions.
- `agent_docs/project_progress.md` — completed vs pending work.
- `agent_docs/latest_session_work.md` — exact current continuation point.
- `agent_docs/workflow/orchestrator_builder.md` — Orchestrator/Builder/GitHub workflow.
- `ASSET_REGISTRY.md` — stable asset identities and superseded variants.
- `QISKIT_ORCHESTRATOR_HANDOFF_V1.md` — self-contained fresh-chat handoff.

Recommended use:
1. Upload the repository-context files to GitHub.
2. Keep the handoff file in the repo as well, or upload it directly when starting a fresh Web Orchestrator chat.
3. Once a repository exists, update these docs from repository truth after each major milestone.
